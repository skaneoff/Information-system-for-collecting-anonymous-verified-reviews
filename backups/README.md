# Резервное копирование и восстановление

В этой папке находятся скрипты для создания резервных копий PostgreSQL и медиа-файлов, а также для восстановления системы из этих бэкапов.

Файлы:
- `backup.sh` — создает SQL-дамп базы данных и архивирует папку с медиа (по умолчанию `uploads`).
- `restore.sh` — восстанавливает базу данных и медиа из созданных бэкапов.

Использование:

1) Подготовьте файл `.env` в корне проекта с настройками подключения к БД (или задайте переменные окружения):

```bash
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=secret
DB_NAME=mydb
# Опционально: если PostgreSQL в Docker, укажите POSTGRES_CONTAINER=name_or_id
# MEDIA_DIR=uploads
```

2) Создание бэкапа:

```bash
chmod +x backups/backup.sh backups/restore.sh
./backups/backup.sh
```

После выполнения появятся файлы:
- `backups/data/db_backup_<TIMESTAMP>.sql`
- `backups/media/media_<TIMESTAMP>.tar.gz`

3) Восстановление (скрипт попросит подтверждение):

```bash
./backups/restore.sh
# или указать явно файлы:
./backups/restore.sh backups/data/db_backup_2026_06_10_120000.sql backups/media/media_2026_06_10_120000.tar.gz
```

Что делают скрипты:
- `backup.sh` читает `.env`, делает SQL-дамп (через `pg_dump` или внутри Docker-контейнера, если задан `POSTGRES_CONTAINER`) и упаковывает папку с медиа в `tar.gz`.
- `restore.sh` по умолчанию подбирает последний дамп и архив медиа, очищает схему `public` (DROP SCHEMA public CASCADE; CREATE SCHEMA public;), применяет SQL и распаковывает медиа в `MEDIA_DIR`.

Рекомендации по тестированию (на тестовой среде):
1. Добавьте тестовые записи и файлы в приложение.
2. Выполните `./backups/backup.sh` и убедитесь, что бэкапы созданы.
3. Смоделируйте потерю данных: удалите таблицы БД или саму базу, удалите папку `uploads/`.
4. Выполните `./backups/restore.sh` и проверьте, что данные и файлы восстановлены.

Git и безопасность:
- Папка `backups/` добавлена в `.gitignore` — в репозиторий не должны попадать сами дампы и архивы.
- Скрипты не содержат хардкода паролей: берут значения из `.env` или переменных окружения.

Подсказки для преподавателя/демонстрации:
- Показать запуск `./backups/backup.sh` и наличие файлов в `backups/`.
- Показать удаление данных и запуск `./backups/restore.sh` с последующей проверкой работоспособности приложения.
